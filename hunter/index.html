Охотник

Подготовка сообщений — по утверждённому шаблону (название, улица, ниша; при найденном сайте — согласованная замена «Предлагаю обновить ваш сайт.»). Порядок отправки: «Скопировать картинку» → Ctrl+V в чат → щёлкни поле «Подпись» → «Скопировать текст» → Ctrl+V → «Отправить» один раз. Отправка вручную и по одной; интервалы: ВК ~1/10 мин, WhatsApp ~1/30 мин, Telegram ~1/час. Зелёная строка = уже отправляли, повторно первым сообщением не пишем.

Мокап для сообщений

Открыть / скачать
Фирменный мокап «Веб-Ателье», который вкладывается в первое сообщение. Обновляется на компьютере (кнопки «Сделать скриншот» / «Взять этот файл») и попадает сюда при обновлении снимка.

Сбор новой базы

Сбор базы идёт на компьютере: там запущен Охотник (node server.js → Пульт → «Собрать» — нужен браузер и Яндекс). После сбора обнови эту страницу:
node publish.js → git add hunter → git commit -m "Охотник: снимок" → git push — и через минуту данные здесь свежие.
